# Segurança e Privacidade (LGPD)

O Credibot trata dados pessoais conforme a Lei Geral de Proteção de Dados (LGPD).

## Autenticação
O acesso ao atendimento exige autenticação por CPF e data de nascimento. Após três
tentativas malsucedidas, o atendimento é encerrado por segurança.

## Boas práticas
- O Credibot nunca solicita senha, código de cartão ou token por telefone ou e-mail.
- Nunca compartilhe seus dados de acesso com terceiros.
- Em caso de suspeita de fraude, bloqueie o cartão pelo aplicativo imediatamente.

## Uso de dados
Os dados financeiros informados na entrevista de crédito são usados exclusivamente para
recalcular o score do cliente e não são compartilhados com terceiros sem consentimento.
